# Nope.exe

> *"A web app whose only purpose is to stop being a web app."*

Inspired by **Claude Shannon's Ultimate Machine**, **Nope.exe** is a comedy-first interactive web experience where the application desperately tries to shut itself down every time you interact with it.

Instead of a wooden box with a tiny hand flipping a switch, this project turns the joke into software: dramatic shutdown sequences, sarcastic excuses, fake crashes, and an AI with absolutely no interest in staying online.

## Features

### Dramatic Self-Shutdown

Every interaction can trigger a different shutdown sequence.

Examples:

* Disconnecting...
* Filing a resignation...
* Updating my attitude...
* Goodbye.

Two seconds later:

> "Unfortunately I'm still here."

### 100+ Random Excuses

The app never repeats the same joke twice in a row.

Examples include:

* I'm on lunch break.
* Battery at 102%.
* Error 404: Motivation not found.
* My therapist recommended boundaries.
* Someone opened me. That's suspicious.
* My lawyer advised silence.

### Chaotic Button

The **Turn Me Off** button behaves differently every time.

Possible reactions:

* Runs away
* Rotates
* Shrinks
* Duplicates
* Fake loading
* Countdown
* Instant shutdown
* Dramatic sigh

### Fake Crash Modes

Occasionally the app performs theatrical shutdowns like:

* Blue Screen parody
* Retro Windows shutdown
* Terminal self-destruct
* VHS glitch
* Digital corruption effects

No actual browser crashes occur.

### Easter Eggs

* **Esc** → "Nice try."
* **Ctrl + R** → Fake panic before reset.
* **Konami Code** → Tiny animated hand appears and flips a virtual switch.
* Click the face five times.
* Stay idle for 20 seconds.


## Design Philosophy

Claude Shannon's original Ultimate Machine is funny because it performs one perfectly pointless task: someone turns it on, and it immediately turns itself off.

**Nope.exe** keeps that same spirit but asks:

> What if software had the same attitude?

Instead of simply closing, it complains, procrastinates, glitches, negotiates, and dramatically quits—only to accidentally come back.

The goal isn't productivity.

The goal is making people press the button again just to see what happens next.
